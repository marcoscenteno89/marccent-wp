# Marccent WP

A WordPress block theme on the Marccent design system ([marccent-theme](https://github.com/marcoscenteno89/marccent-theme)): the same look, theme engine and components as the Marccent Next.js site.

It is the page frame only (templates, header and footer parts, `theme.json`). The styles, the runtime and the blocks come from the [Marccent Blocks](https://github.com/marcoscenteno89/marccent-blocks) plugin, which it requires.

Related plugins: [Marccent Local](https://github.com/marcoscenteno89/marccent-local) (local business details, area pages, SEO) and [Marccent Content](https://github.com/marcoscenteno89/marccent-content) (custom post types, fields and loops).
